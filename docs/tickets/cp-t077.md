## Description

The iranti-site ships an `IrantiMark` SVG component used as the product logo mark in the site's navigation header. The Iranti Control Plane previously had no logo — just a text label. This ticket ported the `IrantiMark` SVG from iranti-site into the control plane and updated `AppShell.tsx` to render it in the app's navigation header.

This ensures the control plane is visually identified as belonging to the Iranti product family. The logo mark now appears in the top-left of the AppShell chrome, adjacent to the app title.

---

## What Was Done

- Ported the `IrantiMark` SVG from iranti-site as a React component into `src/client/src/components/IrantiMark.tsx` (or equivalent path).
- Updated `AppShell.tsx` to import and render `IrantiMark` in the navigation header.
- The SVG renders correctly in both dark and light mode (either by using `currentColor` or explicit palette-aware fills).
- The logo mark is appropriately sized for the nav header without overwhelming the navigation items.
